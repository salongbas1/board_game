# 🎲 board_game — Hearts x8 & ตำนานผู้กล้า (D&D Party Room)

> "(Free) this enjoy all time ❤️"

โปรเจกต์เว็บเกม **หลายคนผ่าน LAN** ที่รันด้วย Node.js + WebSocket ล้วนๆ (ไม่มี framework หนัก ๆ ไม่มี build step) ประกอบด้วย 2 เกมหลักที่เลือกเล่นได้จากเมนูเดียวกัน:

1. **Hearts x8** — เกมไพ่ Hearts คลาสสิก เล่นได้ 4 หรือ 8 คน พร้อมบอท AI
2. **ตำนานผู้กล้า (D&D Party Room)** — เครื่องมือช่วย DM คุมเกม D&D-style เต็มรูปแบบ: สร้างตัวละคร, แผนที่/token, fog of war, ต่อสู้, ร้านค้า, เทรด, ไอเทม, permadeath และอีกมากมาย

ออกแบบมาให้เล่นกันในวงแลนบ้าน/ปาร์ตี้เพื่อน เปิดเซิร์ฟเวอร์เครื่องเดียวแล้วให้ทุกคนต่อผ่าน browser ในวงเดียวกัน

## คุณสมบัติเด่น

- 🖥️ **ไม่ต้องติดตั้งอะไรฝั่งผู้เล่น** — เปิดเบราว์เซอร์แล้วต่อ IP เครื่อง host ได้เลย ไม่มี build step, ไม่มี framework ฝั่งหน้าบ้าน (vanilla JS + CSS ล้วน)
- 🔌 **Real-time ผ่าน WebSocket เดียว** — ทั้ง Hearts และ D&D ใช้ WebSocket connection เดียวกัน แยกกันด้วย prefix ของ `msg.type` (`dnd...` เข้าห้อง D&D, ที่เหลือเข้าห้อง Hearts)
- 🎮 **สองเกมอิสระจากกัน 100%** — โมดูล `server/hearts.js` และ `server/dnd.js` ไม่พึ่งพากันเลย เพิ่ม/แก้เกมนึงไม่กระทบอีกเกม
- 🤖 **บอท AI ใน Hearts** — เล่นไม่ครบคนก็เติมบอทเข้าไปได้ ปรับระดับความยากได้ 3 ระดับ
- 🗺️ **ระบบแผนที่ + fog of war เต็มรูปแบบใน D&D** — หลายแผนที่พร้อมกัน, วาดกำแพง, วิสัยทัศน์แยกรายคน/แชร์เป็นกรุ๊ป, ลาก token ได้แบบ real-time
- ⚔️ **ระบบต่อสู้กึ่งอัตโนมัติ** — ทอย attack roll เทียบ AC, คำนวณดาเมจ, สถานะ (buff/debuff), initiative/turn order พร้อม auto-append คิวเทิร์นเมื่อมีคนเข้าใหม่ระหว่างรอบ
- 🎒 **เศรษฐกิจในเกมครบวงจร** — กระเป๋าไอเทม, ร้านค้า (ซื้อ-ขาย), ตีเสริมของ (forge), เทรดข้ามผู้เล่น, ทองคำ
- ☠️ **Permadeath system** — โดนดาเมจครั้งเดียวเกิน 2 เท่าของ HP สูงสุด = ตายถาวร ไอเทม/สกิลชุบชีวิตใช้ไม่ได้ ต้องรอ DM เพิ่ม HP ให้เท่านั้น
- 🧬 **เผ่าพันธุ์ให้เลือก 58 แบบ** ครบตามฐาน D&D 5e (ไม่ใช่แค่ 8 เผ่าพันธุ์คลาสสิกอีกต่อไป) แต่ละเผ่ามีโบนัสค่าสเตตัสและ race passive สกิลติดตัวประจำเผ่าของตัวเอง (2 สกิลต่อเผ่า)
- 👻 **ระบบอัญเชิญ (Summon)** — token สัตว์/พรรคพวกที่ผู้เล่นอัญเชิญขึ้นมา แยกให้เห็นชัดบนแผนที่ด้วยขอบเส้นประสีฟ้าอ่อน (ต่างจาก NPC ของ DM ที่เป็นเส้นทึบ)
- 💬 **Quick Chat แบบป๊อปอัป** พิมพ์คุยกันไวระหว่างเล่นได้โดยไม่บังหน้าจอหลัก
- 💾 **เซฟ/โหลดสถานะห้อง D&D ทั้งก้อนเป็นไฟล์ JSON** — พักเกมแล้วมาต่อวันหลังได้
- 🇹🇭 **UI และ log ทั้งหมดเป็นภาษาไทย** ออกแบบมาให้กลุ่มเพื่อนคนไทยเล่นด้วยกันสบาย ๆ

## สแต็กเทคโนโลยี

| ส่วน | เทคโนโลยี |
|---|---|
| Backend | Node.js (plain `http` + `ws` module — ไม่มี Express) |
| Realtime | WebSocket (ไลบรารี [`ws`](https://www.npmjs.com/package/ws) ตัวเดียวเป็น dependency หลัก) |
| Frontend | HTML + CSS + Vanilla JavaScript (ไม่มี React/Vue, ไม่มี bundler) |
| State | เก็บใน memory ฝั่ง server ล้วน ๆ (in-process variables) + export/import เป็น JSON สำหรับ D&D |
| Persistence | ไม่มีฐานข้อมูล — ใช้การ export/import ไฟล์เซฟ (D&D) แทน |

Dependency ทั้งหมดของโปรเจกต์ (ดูจาก `package.json`):

```json
{
  "name": "hearts8-lan",
  "dependencies": { "ws": "^8.21.1" }
}
```

## เริ่มต้นใช้งาน

### ความต้องการของระบบ
- Node.js (แนะนำเวอร์ชัน 18 ขึ้นไป)
- ทุกเครื่องที่จะเล่นต้องอยู่ในวงแลน/Wi-Fi เดียวกันกับเครื่องที่รันเซิร์ฟเวอร์ (หรือจะเปิด public/เปิดพอร์ต forward เองก็ได้)

### ติดตั้งและรัน

```bash
git clone https://github.com/salongbas1/board_game.git
cd board_game
npm install
npm start
```

`npm start` จะรัน `node server/index.js` ซึ่งเปิด HTTP + WebSocket server บนพอร์ตเดียวกัน (ค่าเริ่มต้นคือ `3000` อ่านจาก environment variable `PORT` ได้ด้วย)

### เข้าเล่น

1. หาค่า IP วง LAN ของเครื่องที่รันเซิร์ฟเวอร์ (เช่น `192.168.1.10`)
2. ให้ผู้เล่นทุกคนเปิดเบราว์เซอร์ไปที่ `http://<IP เครื่อง host>:<พอร์ต>`
3. จากหน้าเมนูหลัก เลือกเกมที่จะเล่น: **Hearts** หรือ **ตำนานผู้กล้า**

## เกมที่ 1: Hearts x8

เกมไพ่ Hearts (หัวใจ) แบบดั้งเดิม แต่รองรับผู้เล่นได้มากถึง 8 คนพร้อมกันด้วยการใช้ไพ่ 2 สำรับ

### โหมดที่รองรับ

| โหมด | ผู้เล่น | จำนวนสำรับไพ่ | คะแนนตัดจบเกม |
|---|---|---|---|
| 4 คน | 4 | 1 สำรับ | 100 แต้ม |
| 8 คน | 8 | 2 สำรับ | 150 แต้ม |

โฮสต์ห้อง (คนแรกที่สร้างห้อง) เป็นผู้เลือกโหมดและระดับความยากของบอท (`easy` / `normal` / `hard`) ได้ในหน้าห้องรอ

### กติกาเกมโดยสรุป
- ห้ามทิ้งไพ่แต้ม (♥ หรือ ♠Q) ในกองแรกของเกม ถ้ายังมีดอกอื่นให้เดินตาม
- **Shoot the Moon** (กินหมดกระดาน) — เก็บโพแดงทั้งหมด + ♠Q ได้ครบ 52 แต้มในตาเดียว จะพลิกคะแนน (ตัวเองได้ 0 คนอื่นได้ 26 แต้ม)
- **J♦ (แจ็คข้าวหลามตัด)** — มี 2 ใบเมื่อเล่นโหมด 2 สำรับ ให้ -10 แต้มพิเศษ แยกคำนวณจากระบบ Shoot the Moon เสมอ
- ที่นั่งที่ขาดคนเล่นสามารถเติมด้วยบอท AI ได้ทันที

### ผู้เล่นเชื่อมต่อได้ยังไง
ทุกข้อความที่ไม่ได้ขึ้นต้นด้วย `dnd` จะถูกส่งไปให้ `server/hearts.js` จัดการ (ล็อบบี้, การจับที่นั่ง, การเล่นไพ่, แชท)

## เกมที่ 2: ตำนานผู้กล้า (D&D Party Room)

ไม่ใช่เกม D&D เต็มรูปแบบ แต่เป็น **เครื่องมือดิจิทัลสำหรับ DM** ที่ใช้คุมปาร์ตี้ผ่านหน้าจอแทนกระดาษ/ลูกเต๋าจริง เหมาะกับกลุ่มที่เล่น tabletop RPG กันเป็นประจำ

### บทบาทในห้อง
- **คนแรกที่เข้าห้อง = DM โดยอัตโนมัติ** มีสิทธิ์ควบคุมทุกอย่างในห้อง (ปรับ HP ผู้เล่น, สร้างมอนสเตอร์, คุมแผนที่ ฯลฯ)
- ผู้เล่นที่เหลือเข้ามาสร้างตัวละครของตัวเอง หรือกลับเข้านั่งที่เดิมที่เคยออกไปได้ (มีรายชื่อ "ที่นั่งที่เคยออกไป" ให้เลือก)

### การสร้างตัวละคร

**เผ่าพันธุ์ (58 เผ่า)** — ครบตามฐาน D&D 5e แต่ละเผ่ามีโบนัสค่าสเตตัสประจำตัว และ race passive สกิลติดตัว 2 สกิล (นิยามอยู่ใน `server/data/characters.js` และ `server/data/skills.js`) 8 เผ่าพันธุ์คลาสสิกที่พบบ่อยที่สุด:

| เผ่าพันธุ์ | โบนัส |
|---|---|
| 🧑 มนุษย์ | STR+1, DEX+1, CON+1 |
| 🧝 เอลฟ์ | DEX+2, INT+1 |
| 🧔 ดวาร์ฟ | CON+2, STR+1 |
| 🍀 ฮาล์ฟลิง | DEX+2, CHA+1 |
| 💪 ออร์ค | STR+2, CON+1 |
| 😈 ทิฟลิง | CHA+2, INT+1 |
| 🎩 โนม | INT+2, DEX+1 |
| 🐉 ดราก้อนบอร์น | STR+2, CHA+1 |

อีก 50 เผ่าพันธุ์ที่เหลือ (ตัวอย่าง): 🐍 เมดูซ่า · 😇 อาซิมาร์ · 🏔️ โกไลแอธ · 🌗 ครึ่งเอลฟ์ · 💢 ครึ่งออร์ค · 🦅 อารักโคครา · 🐒 แฮโดซี · 🐇 แฮเรงกอน · 🐈 ทาแบ็กซี · 🐢 ทอร์เทิล · 🐺 ชิฟเตอร์ · 🔱 ไทรทัน · ⚙️ วอร์ฟอร์จ · 🐍 ยวนที และอื่น ๆ อีกมาก — ดูรายชื่อเต็มพร้อมโบนัสในไฟล์ `server/data/characters.js`

**คลาส (8 คลาส)** — แต่ละคลาสมี hit die, ประเภทเกราะที่ใส่ได้ และชุดอุปกรณ์เริ่มต้นของตัวเอง:

⚔️ นักรบ · 🔮 นักเวท · ✨ นักบวช · 🗡️ โจร · 🏹 เรนเจอร์ · 🪓 บาร์บาเรียน · 🛡️ พาลาดิน · 🎵 บาร์ด

**ระบบ Point-Buy** — ผู้เล่นแจกแต้มค่าสเตตัส (STR/DEX/CON/INT/WIS/CHA) เองตามงบที่กำหนดตอนสร้างตัวละคร และได้แต้มเพิ่มทุกครั้งที่เลเวลอัพ

**การแต่งหน้าตา** — ทรงผม/สีผม/สีหน้า ปรับได้เองทุกเมื่อโดยไม่ต้องรอ DM ปลดล็อก (ไม่กระทบกติกาเกม)

### ระบบแผนที่และวิสัยทัศน์ (Fog of War)

- DM สร้าง/สลับ/เปลี่ยนชื่อ/ลบแผนที่ได้หลายแผนที่พร้อมกัน มอนสเตอร์และกำแพงผูกติดกับแผนที่ที่สร้างตอนนั้น
- DM เลือกได้ว่าผู้เล่นคนไหน "อยู่ในแผนที่" ปัจจุบันบ้าง (ติ๊กเลือกทีละคน) — ถ้ายังไม่เลือกใครเลย ทุกคนจะเห็นแผนที่มืดสนิท
- ระบบวิสัยทัศน์ 2 ชนิด: **ปกติ** และ **Darkvision (มองในที่มืด)** ปรับรัศมีแยกรายคนได้
- **แชร์วิสัยทัศน์ในปาร์ตี้** — เปิดแล้วสมาชิกทีมที่ยังไม่หมดสติจะรวมพื้นที่มองเห็นกัน แบ่งเป็นกรุ๊ปได้หลายกรุ๊ป (แต่ละกรุ๊ปแชร์กันเองเท่านั้น)
- DM วาดเส้นกำแพงลงบนแผนที่เพื่อกันสายตา/แสดงผังห้องได้
- Token (ตัวละครผู้เล่น/มอนสเตอร์) ลากย้ายตำแหน่งบนแผนที่แบบ real-time ทุกคนเห็นพร้อมกัน

### ระบบลำดับเทิร์น (Turn Order)

- DM กด "เริ่มเทิร์น" → ระบบสุ่มลำดับผู้เล่น (เฉพาะที่อยู่ในแผนที่ปัจจุบัน) + มอนสเตอร์ทุกตัวบนแผนที่นั้น (สุ่มเรียงลำดับ ไม่ทอย initiative)
- DM ลากจัดลำดับใหม่เองต่อได้ตามใจ หรือกด "ตาถัดไป" วนลูปไปเรื่อย ๆ
- ถ้าระหว่างนับเทิร์นอยู่มีผู้เล่น/มอนสเตอร์ใหม่ถูกเพิ่มเข้าแผนที่ปัจจุบัน จะถูก**ต่อท้ายคิวให้อัตโนมัติ**ทันที ไม่ต้องกด "เริ่มเทิร์น" ใหม่ (ซึ่งจะสุ่มลำดับทั้งหมดใหม่)
- ตาของมอนสเตอร์ ผู้เล่นจะกระทำการไม่ได้ ต้องรอ DM สั่งมอนสเตอร์เอง

### ระบบต่อสู้

- คำนวณ AC / HP ตามค่าสเตตัสและอุปกรณ์ที่สวมใส่โดยอัตโนมัติ (`combat-math.js`)
- ทอย attack roll เทียบ AC เป้าหมาย และทอยดาเมจตามอาวุธ
- ระบบ **สถานะ (status effects)** ติดตัวละคร/token ได้ (buff/debuff) พร้อมวันหมดอายุ
- **Permadeath**: ถ้าโดนดาเมจครั้งเดียวเกิน **2 เท่าของ HP สูงสุด** ตัวละครจะ**ตายถาวร** — ไอเทมหรือสกิลชุบชีวิตใช้ปลุกไม่ได้เลย ต้องรอให้ DM เพิ่ม HP ให้เท่านั้นถึงจะกลับมาได้

### เศรษฐกิจในเกม

- **กระเป๋าไอเทม (Bag)** — เก็บของได้จำกัดจำนวนช่อง (ความจุ 20 ช่อง)
- **ร้านค้า (Shop)** — DM สร้างร้านได้หลายร้าน มี 2 ประเภท: ร้านขายไอเทมทั่วไป และร้าน**ตีเสริมของ (Forge)** ที่มีนโยบายเมื่อตีพลาดให้เลือก (ปลอดภัย/ของเสื่อมระดับ/ของพัง)
- **การเทรด** — ผู้เล่นแลกเปลี่ยนไอเทม/ทองระหว่างกันได้โดยตรง ไม่ต้องผ่าน DM
- **Item Effects** — DM ออกแบบเอฟเฟกต์ไอเทมเองได้ (เช่น ไอเทมฮีล, ไอเทมบัฟสเตตัส)

### อื่น ๆ

- **นาฬิกาในเกม (Game Time)** พร้อมโหมดเดินเวลาอัตโนมัติ ปรับความเร็วได้
- **ป้ายประกาศสถานที่/สถานการณ์** ที่ DM ตั้งให้ทุกคนเห็นพร้อมกันบนจอ
- **สกิลประจำคลาส + พาสซีฟประจำเผ่าพันธุ์** ที่ระบบเตรียมไว้ให้ (ครบทั้ง 58 เผ่า) และ DM ยังออกแบบสกิล/พาสซีฟเพิ่มเองได้ (Custom Passives) หรือแก้ไข override ค่าพาสซีฟที่ระบบเตรียมไว้ให้ก็ได้
- **ระบบอัญเชิญ (Summon)** — อัญเชิญ NPC/สัตว์ขึ้นมาเป็น token แยกต่างหากบนแผนที่ (เส้นขอบประปะสีฟ้าอ่อน) ปลดออกจากสนามได้เมื่อไม่ต้องการแล้ว
- **Quick Chat** หน้าต่างแชทป๊อปอัปขึ้นมาแยกจาก log หลัก คุยกันไวระหว่างเทิร์นได้
- **ระบบเลเวล/EXP** ตามตารางที่กำหนดไว้ล่วงหน้า

## สถาปัตยกรรมเครือข่าย (WebSocket Protocol)

ทั้งสองเกมสื่อสารผ่าน WebSocket connection **เดียวกัน** ที่เปิดจาก `server/index.js`:

```js
wss.on('connection', ws => {
  ws.on('message', raw => {
    const msg = JSON.parse(raw);
    if (msg.type.startsWith('dnd')) {
      dnd.handleMessage(ws, msg);   // ข้อความของห้อง D&D ทั้งหมด
      return;
    }
    hearts.handleMessage(ws, msg); // ข้อความของเกม Hearts (ล็อบบี้/เล่นไพ่/แชท)
  });
});
```

- ข้อความทุกชนิดที่ `msg.type` ขึ้นต้นด้วย `"dnd"` (เช่น `dndJoin`, `dndTurnStart`, `dndTokenMove`) จะถูกส่งเข้าโมดูล `server/dnd.js`
- ข้อความที่เหลือทั้งหมดเป็นของ Hearts (`joinRoom`, `playCard`, ฯลฯ) ส่งเข้า `server/hearts.js`
- แต่ละฝั่ง (DM/ผู้เล่น) จะได้รับ **state broadcast** กลับมาทุกครั้งที่มีการเปลี่ยนแปลงในห้อง เพื่อให้หน้าจอทุกคน sync กันแบบ real-time โดยไม่ต้อง refresh

โมดูล D&D ถูกแตกออกเป็นไฟล์ย่อยใน `server/dnd/` (เช่น `turn-order.js`, `trade.js`, `shop.js`) แล้วประกอบกลับเข้ามาใน `dnd.js` ผ่าน factory function (`createTurnOrder(...)`, ฯลฯ) เพื่อเลี่ยงปัญหา circular require และให้ state ของแต่ละโมดูลจัดการตัวเองได้ แม้ว่า state หลักของห้อง (`dndPlayers`, `dndTokens`, `dndMaps` ฯลฯ) จะถูกแทนที่ทั้งก้อนได้ตอนโหลดไฟล์เซฟก็ตาม

## การเซฟ/โหลดสถานะ D&D

ห้อง D&D รองรับการ **export สถานะทั้งห้องเป็นไฟล์ JSON** (ตัวละครทุกคน, token, แผนที่, กำแพง, ร้านค้า, ลำดับเทิร์น, เวลาในเกม ฯลฯ) และ **import กลับ** เพื่อเล่นต่อในภายหลัง เหมาะกับแคมเปญที่เล่นกันหลายเซสชัน
